# Перезвон 1.0.0

Напоминания перезвонить клиенту. Две программы для Windows (ставить ничего не нужно, просто exe) + сервер с Telegram-ботом.

## Что где

| Файл | Для кого |
|---|---|
| `dist/Перезвон.exe` | операторам — окно на панели задач: «Сегодня», «История», напоминания |
| `dist/Перезвон Админ.exe` | админам — все перезвоны всех комнат за день |
| `server/perezvon_server.py` | сервер (API + бот), один файл, чистый Python 3.9+ |
| `server/install.sh`, `server/perezvon.service` | установка на 89.124.122.158 |
| `src/` | исходники программ, `build.py` — сборка exe |
| `tests/` | автотесты (89), `tests/screens.py` — снимки окон (только сами окна программы) |

## Оператор

1. Запустить `Перезвон.exe`. Он сам копируется в `%LOCALAPPDATA%\Perezvon`, создаёт ярлыки (Пуск, рабочий стол) и включает автозапуск (при автозапуске окно сразу свёрнуто в панель задач — ничего не выскакивает).
2. Ввести свой ник Telegram (`@anna_smirnova`, раскладка не важна) — и всё. На любом компьютере под этим ником те же перезвоны.
3. Программа — обычное окно с кнопкой на **панели задач внизу**. Нажал кнопку — окно открылось; крестик сворачивает обратно (напоминания продолжают работать). **Ctrl+Alt+P** — открыть из любой программы. Подпись кнопки показывает «ждут: N» / «пора звонить: N», при напоминании кнопка мигает.
4. Вкладка **«Сегодня»**: форма (ФИО и входящий номер, заметка, «перезвонить через» — 5/10/15/30 мин, 1/2 ч или своё: `25`, `1ч 30м`, `14:30`, `завтра в 10`) и списки «Ждут перезвона» и «Перезвонили сегодня». Форму можно свернуть в одну кнопку «Новый перезвон» — тогда виден весь список. Enter — добавить, Esc — свернуть окно.
5. Вкладка **«История»**: все перезвоны по датам и времени (новые сверху): кто, номер, когда звонил, перезвонили ли (во сколько) или пропущен; поиск по ФИО, номеру, заметке. Хранится 180 дней.
6. В срок — окно «ПОРА ПЕРЕЗВОНИТЬ» поверх всех окон со звуком: ФИО, крупный номер (клик — копия), заметка; «Перезвонил», «Не дозвонился» (+15 мин), «Отложить 5/15/30 мин/1 ч». Фокус не отбирает. Если не помещаются по высоте — второй столбец.
7. Ctrl+C/V/X/A/Z/Y работают и в русской раскладке, правый клик — меню «Вырезать/Копировать/Вставить».
8. **«Выйти»** в шапке окна: досылает неотправленное на сервер, убирает перезвоны с этого ПК (следующий человек их не увидит) и предлагает войти. После входа на любом ПК всё возвращается с сервера.
9. Нет связи с сервером — всё работает и хранится на ПК, отправится само.

**Где что хранится:** данные входа — `%LOCALAPPDATA%\Perezvon\Data\session.bin` (скрытая папка, файл целиком зашифрован DPAPI — читается только этой учётной записью Windows на этом ПК); настройки и перезвоны — `%APPDATA%\Perezvon` (`settings.json` без данных входа, `items.json`). Админка — `%LOCALAPPDATA%\PerezvonAdmin\Data`.

## Роли (создаются в Telegram-боте)

- 👤 **Оператор** — создаёт перезвоны в «Перезвон.exe», видит только свои.
- 🛡 **Админ** — только смотрит, и только СВОЮ комнату: «Перезвон Админ» + в боте «Сегодня»/«Пропущенные»; получает пропущенные своей комнаты. Перезвоны не создаёт и не меняет, пользователями не управляет.
- 👑 **Супер-админ** — всё: все комнаты, отметки «перезвонили»/удаление в админке, пользователи, комнаты, роли (в т.ч. другие супер-админы).
- Админы и супер-админы в «Перезвон.exe» не входят — для них «Перезвон Админ».
- **Владелец** — Telegram ID `8267218455` (в `config.json` → `owners`): всегда супер-админ, его нельзя понизить, отключить или удалить. Достаточно нажать «Старт» в боте.

Создать пользователя: в боте «➕ Создать пользователя» (ник → имя → комната → роль), или одной строкой
`/adduser @anna_smirnova; Анна Смирнова; vn2; оператор` (роль: оператор / админ / супер-админ), или просто прислать боту `@ник`.
Если у человека нет ника — в карточке «🔑 Код входа» (12 цифр, вводится вместо ника).
Пропущен = просрочен больше чем на 10 минут (`missed_grace_min`).

## Сервер

`/opt/perezvon/perezvon_server.py`, данные `/var/lib/perezvon` (`perezvon.db` + `config.json`, 600), служба `perezvon`
(пользователь `perezvon`, 127.0.0.1:8767), nginx `location /perezvon/` в `sites-available/sidekick-https`.
Адрес для программ: `https://89.124.122.158/perezvon`.
`config.json`: `bot_token`, `owners`, `tz` (Europe/Moscow), `missed_grace_min`, `login_confirm`
(true — вход по нику ещё и подтверждается кнопкой в Telegram; по умолчанию выключено по просьбе).

## Сборка и тесты

```
python build.py                                   # dist/*.exe (нужны pyinstaller, pillow — только тут)
cd tests && python -m unittest test_common test_server test_bot test_gui
set PEREZVON_REAL_INPUT=1                         # + тесты настоящими нажатиями (не печатать в это время!)
python screens.py                                 # снимки окон в tests/screens
```

## Известное

- Вход только по нику: кто знает чужой ник — войдёт под ним. Включить подтверждение: `"login_confirm": true`.
- Заголовок окна админки красится в цвет акцента Windows, если в системе включено «Показывать цвет в заголовках».
- exe собран PyInstaller'ом: редкие антивирусы ругаются на такие файлы — тогда добавить в исключения.
